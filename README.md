# 自动上滑

刷短视频时，不想一直用手往上滑，可以把这件事交给它。打开后点一下「开」，它会隔一段时间自动向上滑一次，中间你可以歇着。

这是装在你自己手机上的小工具，只在你点了「开」之后才滑动。

## 下哪个、怎么装

到 [Releases 页面](https://github.com/QL796907/scrolling/releases/latest) 下载 **`autoswipe.apk`**，用手机打开这个文件并安装。

系统可能会说「来源未知」，允许给这个文件管理器或浏览器安装即可。装好后，桌面上会出现「自动上滑」。

已经装过旧版的，直接装新版覆盖就行，不用先卸载。

## 第一次怎么用

按主页从上到下，把这几项打开（一般只用开一次）：

1. **无障碍**  
   去系统设置里找到「自动上滑」，打开开关。  
   如果打开后马上自己关掉：先点应用里的「允许受限制的设置」，进应用详情后点右上角三个点，允许之后再回来打开无障碍。

2. **悬浮窗**  
   允许后，屏幕侧边会出现「开 / 停」。

3. **电池不优化（建议开）**  
   关掉电池限制，并允许自启动。不然手机歇一会儿，滑动也可能一起停。

然后点侧边的 **开**。到点了会自动往上滑一下。点 **停** 就暂停。把侧边栏往外拖一段，会收成一条箭头；点主页的「收起侧边栏」会完全隐藏，要用时再点「显示侧边栏」。

滑得快慢在主页改，默认大概一到两分钟随机滑一次。

## 几点容易卡住的地方

- 第一次点更新或安装时，要允许「自动上滑」安装应用，再回来点一次安装。
- 想在应用里检查更新，需要把这个 GitHub 仓库设为公开。现在如果还是私有的，检查更新会失败，但不影响你已经装上的功能。
- 换电脑打出来的安装包，有时不能直接覆盖，需要先卸载再装。同一台电脑打的包一般没问题。

## 这次更新（1.9）

- 打开应用时，顶部时间、电量不再闪个不停。
- 点权限按钮会跳到对应的系统设置，不会没反应或闪退。
- 点「收起侧边栏」后，回到主页不会再自动弹出来。
